# Getting help

Start with [QUICKSTART.md](QUICKSTART.md), [INSTALLATION.md](INSTALLATION.md), [settings guidance](project/ai_workflow/settings.md) and [backend setup](project/ai_workflow/knowledge_backends.md).

Use a [bug report](https://github.com/ocagdas/repo_pilot/issues/new?template=bug_report.yml) for reproducible failures or a [feature request](https://github.com/ocagdas/repo_pilot/issues/new?template=feature_request.yml) to discuss improvements. Include the Repo Pilot version, Python version, OS and a minimal disposable example. Redact credentials, private code, graph contents and personal paths from logs.

For vulnerabilities, follow [SECURITY.md](SECURITY.md). For conduct concerns, follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Support is best effort; platform and backend coverage is described in [VALIDATION.md](VALIDATION.md).
