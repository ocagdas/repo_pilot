# Knowledge implementation limits

The retained utility creates file inventories, branch deltas and local overlay records. It checks basic manifest declarations. It does not execute semantic adapters, merge clangd indexes, authenticate publishers or prove compiler dependency coverage. Required mode rejects missing necessary current layers. Auto mode permits partial navigation with source verification.

compile_commands.json supplies compilation instructions and is not itself a semantic index. Future adapters must validate repository identity, compiler and target context, inputs and checksums. Shared publication remains external. Local caches have no automatic retention worker. Serialize bootstrap writes per worktree. Cold and changed inventory checks hash selected files and have not been benchmarked on a large repository.
